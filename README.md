# Shiori

<img src="assets/branding/shiori-chibi-logo-v1.png" alt="Shiori" width="160" />

一款面向 Android 和 iOS 的轻小说阅读器，使用 Flutter 构建。以书架和阅读为中心，支持在线书源与本地 TXT / EPUB。

目前用于个人和私下测试，仓库为 private。核心功能已形成 **1.0.0 的功能基线**；代码版本仍为 `0.1.0+1`，尚未发布正式 1.0.0。

## 功能

- **书架与继续阅读**：收藏书籍、查看目录、恢复阅读位置。
- **在线阅读**：主动搜索、书籍详情、分卷目录、图文阅读；已缓存内容可离线阅读。
- **本地导入**：通过文件选择、系统打开或分享导入 TXT、无 DRM 的流式 EPUB 2/3；支持编码预览、重复文件识别和本地目录跳转。
- **阅读排版**：字号、行距、段距、页边距和纸张主题；章节标题、首行缩进、大图页面及部分 EPUB 特殊排版。
- **分页阅读**：左右点按或拖动翻页，章节内外共用简化纸张翻页效果；保留语义进度，调整排版后恢复位置。
- **外观与语言**：浅色、深色、跟随系统；青绿、蓝灰、暖棕、淡粉强调色；中文与英文界面。
- **缓存管理**：当前章节图片及有限下一章预取，按书或全部清理缓存。

首页没有发现或推荐入口。在线功能目前只有一个书源，服务可用性可能变化；应用不附带小说内容。

## 使用

首页右上角搜索在线书籍；通过「更多 → 导入」选择本地文件。系统分享入口收到文件后，回到应用确认导入。

阅读时点按正文中间显示工具栏，点按两侧或左右拖动翻页。目录用于选章，阅读设置调整排版，「恢复默认」重置阅读设置。

导入后，文件由应用保存副本。移出书架、清理缓存和删除本地书籍是不同操作：前两者不会删除托管原件；删除本地书籍不会删除导入前的外部文件。

目前不支持 DRM、PDF、完整固定版式 EPUB、云同步或整本在线下载。EPUB 的普通正文使用统一排版，部分短扉页保留原书样式，并非完整浏览器级 EPUB 兼容。

## 本地开发

固定 Flutter **3.38.4** / Dart **3.10.3**。Android 使用 JDK 17、SDK 36、NDK 28.2.13676358；iOS 最低部署版本为 15.0，构建需要 macOS / Xcode。

```sh
fvm install 3.38.4
export PUB_HOSTED_URL=https://pub.flutter-io.cn
fvm flutter pub get --enforce-lockfile
fvm flutter devices
fvm flutter run --target lib/main.dart
```

Android 最低 API 24。最低部署版本不代表已在所有受支持系统上实测。完整环境、离线检查、开发入口和 iOS 签名配置见[开发说明](docs/development.md)。

## 素材与数据

书架、进度、偏好和导入文件保存在应用本地；在线查询会发送给相应服务。系统备份或换机迁移可能包含用户数据，详见[发布说明](docs/release/README.md)。

角色品牌素材参考《更衣人偶坠入爱河》的乾纱寿叶，目前没有授权证明；项目尚未选择代码许可证，书源与内容许可也未确认。私有仓库和私下测试不构成素材或内容的再分发授权。
