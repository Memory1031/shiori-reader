# Shiori 1.3.0 Beta 1

这是 1.3.0 的首个测试版，主要用于验证真实 GitHub 发布、签名清单以及 Android 和 Windows 的应用内自动升级链路。Windows 桌面界面后续仍会继续重构。

相对 v1.2.1，本版包含：

- 调整书架列表、书籍详情、离线内容和本地书籍页面；在详情页预览本地目录，并改进章节标题与当前位置的目录定位。
- 改进全书阅读进度、完成页、跨章节目录依据和阅读位置恢复；调整图片页与章节展示。
- 增加 EPUB Ruby 注音显示，以及保留原版式的 SVG 页面、目录与热点链接支持；让 SVG 页面颜色跟随阅读器主题。
- 在「关于与更新」展示渠道选择与发布说明；Android 支持下载验签后交给系统安装，Windows 支持下载验签后通过独立更新程序重启替换，并改进中断恢复与文件事务校验。
- 将 Flutter 固定工具链更新至 3.38.10。

这是 beta 版本。首次安装本版需要使用 GitHub Release 提供的完整安装包；应用内自动升级将通过后续 beta 构建验收。
