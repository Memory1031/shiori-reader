# 阅读器

## 当前体验

生产阅读器只提供分页：点按两侧、左右拖动、键盘或辅助语义操作翻页，中间点按显示 / 隐藏工具栏。旧偏好中的滚动模式读取为分页，保留其余设置和进度；底层实验视口仍可用于开发，不是产品入口。

页眉展示书名或实际卷名，避免使用文件节点的「标题」等占位名称；页脚显示本章进度。目录选择章节，本地 EPUB 可直接定位条目。进入设置和返回不应重置正文位置。

## 排版

普通中文段落保持左对齐和自然字距，按当前字体与文字缩放测量整字宽度，正文区域最多收窄不足一字并左右居中；测量与绘制使用同一宽度。标题、图片及明确居中/右对齐不调整。标点和中英文混排仍可产生自然参差，不更改正文或持久阅读身份。

单页阅读区域最多宽 680 逻辑像素。普通正文在扣除页边距后可容纳两页（每页至少 500 逻辑像素、页间距 72）时自动并排显示，中缝以随主题变化的淡竖线区分。双页只取决于可用宽度，不区分平台：大屏平板（iPad / Android 横屏）与桌面宽窗同样进入双页，属预期行为；键盘、鼠标等桌面能力另行区分。先左后右，按一组两页翻动；窗口缩放按语义位置恢复。封面、整页插图和特殊 WebView 页面保持限宽居中的单页，章末不足两页时右侧留空。


| 设置 | 默认值 / 行为 |
| --- | --- |
| 正文字号 | 20 logical px |
| 行高 | 1.6 倍字号 |
| 段间距 | 20 logical px |
| 左右页边距 | 五档；适中以每侧 30 logical px 为基准，窄/宽分别多/少一字，极窄/极宽多/少两字 |
| 章节级标题 | 正文 1.4 倍、w700、行高 1.3；默认居中，上下留白 |
| 次级标题 | 正文 1.15 倍、w600，较小上下留白 |

标题留白随段距调整：章节级标题上下各 `(段距 + 64) / 2`，次级标题各 `(段距 + 28) / 2`。明确的右对齐保留。标题与后续正文在空间允许时一起排入下一页，避免标题独占页尾。长段落分块测量，大图按比例单页显示，不将一整章一次性布局。

在线普通中文段落在没有原始缩进时补首行两字缩进；已有前导空白、明确对齐、标题及跨页续段不重复添加。缩进只改变显示，不修改正文或语义身份。本地 EPUB 保留可识别的原始缩进 / 对齐。

设置面板只有一个「恢复默认」，重置阅读设置，保留已看过操作提示的状态。偏好以 300ms 合并写入，点击步进按钮、关闭面板及生命周期节点刷新；失败保留预览和重试能力。

## EPUB 渲染

普通正文走原生分页，保留段落、标题、分隔线和图片。章节开头的最高级标题即使标成 h4 等，也可提升为章节级显示；不能只针对 h1 / h2 优化而遗漏实际文件。

短扉页等特殊内容在满足受限条件时使用静态 WebView 保留竖排、定位、变换等样式；不是把整本 EPUB 交给网页渲染。资源内嵌、脚本关闭、外部请求禁用，具体限制见[本地导入](local-import.md)。特殊页按内容尺寸适配并考虑居中；超长内容可用滚轮或触摸在页内滚动，隐藏滚动条并禁用 WebView 越界回弹，不恢复产品的上下滚动阅读模式。

## 翻页与切章

原生章内与章间共用 [PaperTurnMotion](../lib/features/reader/viewport/paper_turn.dart)：完整行程基准 **280ms**、`easeOutCubic`。拖动释放后按剩余距离折算时间，非零动画最低 80ms；减少动态效果时立即完成。剩余距离不同会导致实际收尾时长不同。

效果为简化纸张折页：空白纸背、渐变与阴影，不截取正文作为背面，不做完整 3D 纸张变形。动画范围覆盖阅读页及页眉、页脚、页边距；正文裁剪使用整页坐标，避免只在中间 content box 内翻动。详见[视口决策](reader.md)。

章内拖动跟手，支持取消；跨章在确认翻页后准备目标内容，保持当前页可见，目标首帧就绪再播放同一动画。当前最多保留一个活动页和一个待提交目标，动画完成后才激活目标进度会话并关闭旧会话。目标失败保留原页并允许重试，不用白屏等待替换。

跨章加载时间不属于 280ms 动画时间；在线目标尚未缓存时仍可能等待。当前没有跨章目标就绪前的跟手预览。图片尺寸更新在翻页期间延后，避免布局中途跳变。WebView 平台视图的裁剪、回弹和实际帧率仍需设备验证。

同一排版下保留已计算页面的轻量起止边界，完整页面仍只缓存当前阅读页组前后三组（单页或双页）。缓存淘汰后的倒翻复用已知边界。进度跳转、恢复和重排显示包含目标语义位置的正向分页，不将目标字强行设为页首；原始页内语义位置仍保留。未知目标从最近的已知正向边界分帧计算，首次深跳可能需要计算章节前缀；普通连续阅读仍按需计算。

倒翻进入上一章时，从章首沿正向分页链分帧寻找末页，使末页及后续倒翻边界与从章首阅读一致。每帧最多计算八页，达到约 4ms 后让出下一帧；准备期间仍显示当前章节，完成后才报告目标就绪和位置。字体、尺寸等排版条件变化会清空边界记录；图片尺寸更新后仍保持章末定位，直到用户翻页或跳转至其他位置。不持久化这些边界，也不提供全局页码。

## 位置与生命周期

持久化的是内容 revision、blockKey、块索引与块内 / 章节比例，不保存像素滚动偏移。改变字体、窗口或内容版本时按语义位置恢复；身份规则见[领域模型](architecture.md)。

进度写入使用会话 generation / sequence 拒绝晚写；未提交的目标章不抢占活动进度。展示标签约 4Hz 更新，不限制真实位置采样。退出和生命周期变化刷新待保存位置，写入失败不能假报已保存。

图片使用独立 lease 和有界解码缓存，释放页面需关闭消费者；章内重排不应重新下载整章。cacheOnly 阅读的正文和图片都不触发在线请求。

## 决策：统一分页与整页翻页

状态：采用。当前产品只提供分页；历史滚动实验保留在开发代码与兼容层，不进入设置面板。

### 选择

普通图文使用原生语义分页，有界测量长段落并保存 blockKey / fraction。少量 EPUB 特殊短页使用受限静态 WebView，保留作者排版。两条路径在阅读页外层共用简化折页覆盖、时长与提交规则。

折页采用裁剪、纸背渐变和阴影，不截图正文、不在背面复刻文字。这能覆盖原生内容与平台视图，避免为动画保存整章位图；代价是没有 Apple Books 那样的真实纸张卷曲与透字。

### 约束

- 动画边界是整张阅读页，包含页眉、页脚和页边距；章内内容需要映射到整页坐标。
- 统一基准 280ms / easeOutCubic；拖动释放按剩余距离收尾，支持减少动态效果。
- 切章准备期间保留当前内容，目标首帧准备好才动画；成功提交后才交接进度会话。
- 同时最多一个活动目标和一个待提交目标；取消、失败、销毁时释放各自资源。
- 保留语义位置，不把动画进度、像素坐标或分页结果持久化为阅读位置。

旧滚动性能测量仅是历史证据，不能代证当前折页性能。

字号、行距、段间距使用加减按钮，步长分别为 1、0.1、2；达到上下限禁用对应按钮。页边距五档使用当前字宽计算，旧数值就近映射档位，恢复默认回到适中。
