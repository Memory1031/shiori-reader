# Shiori 1.0.0

Shiori 首个正式版本，面向 Android / iOS 的轻小说阅读客户端。本次 GitHub Release 提供 Android 安装包。

## 主要功能

- 书架、搜索、小说详情、分卷目录与继续阅读。
- 本地 TXT / EPUB 导入、系统“用其他应用打开”、离线阅读与阅读进度保存。
- 左右分页、字体与排版设置、主题及中英文界面。
- 正文图片缓存、有限预取和存储清理，改善连续阅读体验。
- EPUB 卷内目录跳转、基础注音及特殊短页展示。

## 本次兼容性完善

修复部分 EPUB 的正文丢失、空章节、隐藏内容误显示、图片引用及 ZIP 打包兼容问题。35 个样本文件中 34 个解析成功；含不支持的加密声明的文件仍会拒绝导入。不支持完整 CSS、纯 SVG 绘图、固定版式或 DRM 解密。

## 安装与更新

- 下载下方 `shiori-reader-v1.0.0-android.apk`。`SHA256SUMS.txt` 和 `release-info.json` 提供文件校验及构建信息。
- 此包使用个人发布签名。若之前安装的是 Debug 签名测试包，可能无法直接覆盖安装；卸载会清除应用内数据，请先保留外部小说原件并记录阅读位置。
- 已导入 EPUB 的解析记录不会因升级自动重建；相同文件重复导入会去重。删除后重新导入会清除该书原有进度。
- 此 Release 不提供 iOS 安装包；iOS 仍需通过个人 Xcode 签名安装。

## 已知边界

在线内容取决于第三方书源的可用性。应用不附带小说，不包含整书下载或云同步；部分特殊 EPUB 的排版仍可能与原版不同。
