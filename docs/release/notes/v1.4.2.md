# Shiori 1.4.2

Shiori 1.4.2 新增了 **本机阅读统计**，可以回顾每天的阅读时长、近期阅读趋势以及每本书的阅读记录。

本次更新还增强了 **EPUB 原书排版兼容性**，改善行内强调线、上标注释及中英文混排的显示效果。同时调整了移动端首页导航，优化 Windows 和 macOS 的启动体验，并为 iOS 用户提供 AltStore 订阅源。

## 全新阅读统计

现在可以通过首页的「统计」页面回顾自己的阅读记录。

- **阅读时长**：查看今天及累计阅读时间。
- **阅读趋势**：按最近 7 天、30 天或 12 个月查看阅读情况。
- **分书统计**：了解每本书的阅读时长。
- **交互图表**：点击或拖动查看对应日期的记录。
- **记录管理**：随时暂停新增统计或清空已有数据。

### 尊重隐私的阅读记录

所有阅读统计都保存在本机，不需要账号，也不会上传至云端。

Shiori 仅在阅读器处于有效的前台阅读状态时计时：

- 切换到后台、离开阅读器或打开阻断阅读的面板时暂停。
- 长时间没有阅读操作时自动停止计时。
- 阅读时长与阅读进度分别管理，关闭统计不会影响正常阅读及进度保存。

删除书籍时，会移除其对应的分书统计关联，但已累计的历史总时长仍然保留。用户可以在统计管理中单独清空这些记录。

目前部分使用特殊 WebView 排版的 EPUB 页面暂不计入阅读时长。

## EPUB 阅读兼容性增强

本次重点改善了部分轻小说 EPUB 中容易丢失的行内排版样式。

### 行内强调线

新增对 EPUB 中常见实线、点线和虚线强调的支持。

- 保留作者在正文中指定的行内强调范围。
- 改善强调文字跨行、跨页时的显示。
- 修复中英文混排时，不同字体导致强调线高低错位的问题。
- 相邻且样式相同的强调文字现在可以连续绘制点线或虚线。

例如推理小说中用于提示重要线索的文字强调，现在可以更接近原书的表现。

强调线仍采用适合原生阅读器的绘制方式，不保证与 EPUB CSS 边框逐像素一致。

### 上标注释

支持 EPUB 中明确声明的短文字上标，包括部分注释标号。

- 保留较小字号与上标位置。
- 支持随阅读字号调整。
- 保持正文换行、分页及链接点击功能。

对于没有明确脚注语义标记的旧式注释，继续通过普通书内链接跳转访问，不会强行识别为弹出脚注。

## 阅读性能优化

减少部分不必要的数据查询和文字绘制开销。

- 统计页面不可见、被其他页面覆盖或应用进入后台时，不再持续刷新统计数据。
- 重新打开统计页面时，按需获取最新记录。
- 合并短时间内重复触发的统计查询。
- 优化 EPUB 强调线的绘制计算，避免没有强调装饰的文字执行额外几何查询。
- 改善连续强调文字的绘制处理，减少重复计算。

上述优化不改变原有阅读进度保存和时长记录策略。

## 移动端界面改进

重新整理 Android 和 iOS 的首页导航。

- 书架、阅读统计和设置使用更加清晰的导航入口。
- 设置页面按功能分组，方便查找本地文件、缓存与应用管理功能。
- 切换首页页面时尽量保留书架原有布局与滚动位置。
- 优化底部导航的间距、选中状态及部分界面文案。

## Windows 与 macOS 改进

### Windows

- 启动 Shiori 时，如果应用已经运行，会优先激活现有窗口，避免重复启动多个实例。
- 记住窗口的大小、位置和最大化状态。
- 改善多显示器、DPI 变化及显示器断开后的窗口位置恢复。
- 优化快速关闭、重新打开应用时的稳定性。

### macOS

- 启动期间显示与应用主题协调的原生启动画面，直到 Flutter 首帧完成。
- 改善启动画面的移除时机，避免遮挡已加载的界面。
- 记住窗口位置和大小，并在显示器环境变化时尽量恢复到可见区域。

## iOS AltStore 订阅源

现在提供适用于 **AltStore Classic** 的 Shiori 订阅源。

- 正式版源：提供稳定版本。
- Beta 源：同时提供正式版与测试版。
- 新版本完成发布后，可通过订阅源获取更新信息。

[查看 AltStore 安装和订阅说明](https://github.com/Memory1031/shiori-reader/blob/develop/docs/altstore.md)

iOS 安装包仍为未签名 IPA，需要通过 AltStore 或其他方式完成签名。AltStore 续签、更新和系统分享扩展的可用性取决于实际签名及设备配置。

### 升级说明

**从 v1.4.1 升级**

Android、Windows 和 macOS 的正式发行版本可以通过应用内「关于与更新」检查新版。

iOS 用户请使用原有签名或分发方式完成覆盖更新。

**从 v1.4.0 升级**

由于 v1.4.0 使用旧版更新协议，需要手动下载安装新版，无法直接通过旧版应用内更新机制升级。

### 已有 EPUB 的新样式

本次 EPUB 解析器版本升级至 **33**。

此前导入的 EPUB 可以继续正常阅读，但需要重新解析才能获得新增的行内强调和上标支持。

Shiori 会在合适条件下尝试自动更新旧书的解析结果，也可以从本地文件管理中手动选择「重新解析」。

**无需删除原书重新导入。** 重新解析会尽量保留已有阅读位置和书签；遇到无法安全迁移的情况时，将保留原有数据。
