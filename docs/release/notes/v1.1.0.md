# Shiori 1.1.0

本次更新集中改善本地 TXT / EPUB 兼容性，新增保留阅读位置的重新解析，并改善阅读排版与设置操作。供个人与私下测试使用。

## 更新内容

- 改善 EPUB 目录、图片候选、段落空白及特殊页面的兼容性。
- 改善 TXT 编码预览和章节识别，减少把正文误识别为标题的情况。
- 本地文件菜单新增“重新解析”：使用应用内原件重新处理，尽量恢复阅读位置；无法精确恢复时明确提示。
- EPUB 阅读菜单新增“本章链接”，可打开有效包内脚注或辅助文档，并返回原阅读位置。
- 连续翻章跳过标记为非正文的附录，仍可通过目录进入。

- 改善中文正文左右留白：保持自然字距，微调正文宽度并居中。
- 页边距改为极窄、窄、适中、宽、极宽五档，随字号调整阅读宽度。
- 字号、行距、段间距改用加减按钮，方便精确调整；保留即时预览和“恢复默认”。

## 升级提醒

- 原有页边距设置会映射到最近档位；“恢复默认”使用适中档。
- 覆盖安装需要与旧包使用相同签名，不要为了升级直接卸载应用。
- 已导入书籍不会自动重新解析。若旧书特殊排版显示异常，或想应用本次兼容改进，请进入“更多 → 本地文件 → 书籍菜单 → 重新解析”，完成后重新打开。
- 重新解析会尝试保留进度；删除后重新导入会清除该书进度，两者不同。
- 脚注入口位于“本章链接”菜单，目前不支持直接点击正文链接，也不打开外部网页。

## 安装与支持范围

Android 附件提供 APK、SHA256SUMS.txt 和 release-info.json。iOS 仍需个人 Xcode 签名安装，本次不提供 iOS 安装包。

支持流式 EPUB 的受限排版，不承诺完整 CSS、固定版式、纯 SVG 绘图或 DRM 解密。本地 EPUB 未指定首行缩进时仍保留无缩进。应用不附带小说，不新增整书在线下载或云同步。
