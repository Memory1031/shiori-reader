# Shiori 1.3.0 Beta 4

这是 1.3.0 的第四个测试构建，内部构建号为 14，重点整理移动端界面与阅读器结构，并为后续桌面端 UI 重构准备共享组件和交互基础。

## 阅读体验

- 重构阅读器界面，将目录、阅读进度、设置与顶部/底部工具栏拆分为可复用组件。
- 新增翻页样式选择：仿真翻页、覆盖、滑动和无动画，并改进仿真翻页的视觉表现。
- 移动端阅读时进入沉浸模式，并在阅读界面中显示时间、电量与阅读进度。
- 重新设计阅读设置面板，优化纸张主题、字号、行距、段间距、页边距和翻页样式的调整体验。
- 将原来的「本章链接」整理为「本章注释」，脚注可直接查看内容，章节引用会显示目标位置。
- 统一正文目录与书籍目录入口；修复离线阅读目录重试可能离开缓存模式、目录刷新失败反馈，以及从阅读完成页跳回章内标题后的进度保存。
- 优化返回和详情页导航：阅读器打开作品详情后，返回会回到原阅读位置；从详情页继续阅读或选择章节时避免重复堆叠 Reader 页面。
- 调整阅读界面顶部与底部留白，避免运行标题、时间和进度贴近屏幕边缘。

## 书架与本地内容

- 重构本地书籍页面，突出重新解析流程，并改善 EPUB / TXT 的管理与状态展示。
- 重新设计离线内容页面，按书籍分组展示缓存章节、图片完整度与存储占用。
- 统一书架与本地书籍的列表行样式，改善鼠标悬停、按压、键盘焦点和滑动操作反馈。
- 本地书籍封面在页面切换间复用解析结果，减少重复读取和短暂占位。

## 界面与基础结构

- 统一圆角、间距、动效、阅读纸张和主题样式等 UI token。
- 统一不同平台的页面跳转和交互能力，为后续 Windows 桌面端侧栏、面板和宽屏布局改造做准备。
- 优化宽窗口下的详情页封面尺寸和多处响应式布局。
- 减少阅读器在翻页、进度更新和目录变化时的不必要重建。

> 本版本仍为 Beta。桌面端完整 UI 重构尚未完成，后续测试版本还会继续调整 Windows 的导航、布局与交互。
