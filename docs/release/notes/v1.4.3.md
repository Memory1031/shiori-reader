# Shiori 1.4.3

Shiori 1.4.3 重点改善了 **EPUB / TXT 排版、章节翻页与图片阅读体验**，并进一步完善书架、阅读器弹层和跨平台响应式布局。

本次更新还优化了 **应用内更新界面**，让发行说明更容易阅读，并为直接分发的 iOS 版本增加新版检查能力。

## EPUB 与 TXT 排版改进

### EPUB 图片与版式还原

进一步改善部分轻小说 EPUB 中的图片位置、尺寸和间距：

- 修复部分 SVG 图片与容器对齐不一致的问题，更准确地保留原书布局。
- 改善带有方向信息的图片尺寸判断，减少插图或装饰图片的错误定位。
- 对缺少明确作者对齐方式的独立单图页面，默认在可用阅读区域中居中。
- 修正部分图片周围的留白、纯色背景与图文混排表现。
- 优化重新排版后的页面定位，尽量保持阅读位置和书签的语义对应关系。

复杂的固定版式、特殊 HTML / CSS 页面仍受现有兼容范围限制；并非所有 EPUB 都能与原始排版逐像素一致。

### TXT 段落与中文正文

- 改善 TXT 行尾换行与空行的排版，减少重复段距和不必要的空白。
- 默认将原文空行合并为自然段间距；也可在阅读设置中选择「保留原文空行」。
- 修正标题与正文在分页、跨栏时的间距处理，减少异常留白。
- 改进部分中文段首缩进与复杂字符的分页处理。
- 页边距按当前实际使用的正文字体测量，调整字号或窗口大小时仍按阅读位置恢复。

TXT 空行选项仅改变显示效果，不修改原始文件内容或已有阅读位置。

## 翻页与阅读交互

### 更稳定的跨章节翻页

- 优化相邻章节在加载、准备和切换过程中的翻页体验。
- 减少章节数据刷新、网络或本地读取延迟造成的翻页中断。
- 改善手势取消、加载失败与阅读进度保存等待时的状态处理。
- 在翻页过程中暂缓部分图片尺寸引起的重排，避免页面突然跳动。
- 改善章节末页与全书完成页的定位和返回行为。

现有「仿真」「覆盖」「平移」「无动画」翻页方式保持不变。本次未引入新的 3D 纸张纹理翻页效果。

### 图片预览双击缩放

图片预览现在支持双击放大和再次双击复位：

- 围绕点击位置进行约 2 倍缩放，方便查看插图细节。
- 放大与复位使用短暂的平滑动画。
- 手动拖动、双指缩放或鼠标操作可直接接管当前动画。
- 遵循系统的「减少动态效果」偏好。

## 界面与跨平台适配

### 书架操作更自然

- 空书架时优先展示「导入书籍」，在线搜索保留为次要入口。
- 统一手机书架标题、网格与列表的内容边距。
- 列表侧滑操作现在可以跟随手指移动，并改进取消、回弹与多选状态下的处理。
- 改善较大系统文字下的书名占位和按钮布局。

### 随窗口宽度调整界面

- 根据可用窗口宽度选择底部导航、图标导航栏或侧边导航，而不再仅由操作系统决定布局。
- Windows 和 macOS 的窄窗口也能使用更紧凑的界面。
- 阅读器目录、书签、进度、搜索、注释及设置面板在窄窗口中使用底部弹层，在较宽窗口中使用侧边面板。
- 优化弹层切换、阅读主题同步及部分长文本和大字号下的界面布局。

这些调整继续沿用 Shiori 原有的纸面配色和阅读排版，不改变书架、阅读进度及设置的存储方式。

## 应用更新体验

- 更新页面的发行说明支持在应用内展开、收起，较长的更新内容不再只能查看简短预览。
- 调整下载、安装、权限提示和发布页入口在不同窗口宽度下的排列。
- 直接分发的 iOS / iPadOS 版本现在可以检查新版本、阅读更新说明并打开发布页面。
- TestFlight 版本仍通过 TestFlight 更新；直接分发的 IPA 仍需通过原有签名工具或分发方式更新，不提供应用内下载或覆盖安装。

### 安装注意事项

**Windows：** 推荐使用 EXE 安装版；便携版需要完整解压 ZIP。部分特殊版式 EPUB 在安装 WebView2 Runtime 后可获得更完整的排版还原，缺少运行环境时可能使用原生分页降级。

**macOS：** 打开 DMG 后，将 Shiori 拖入「应用程序」文件夹。当前发行包未经过 Apple Developer ID 签名和公证，首次打开时可能需要在系统「隐私与安全性」中确认。

**iOS：** IPA 为未签名版本，无法直接安装。请使用 AltStore Classic 或其他获支持的方式签名，并通过相同签名身份更新。系统分享扩展的可用性取决于签名及 App Group 授权。

### 从旧版本升级

**从 v1.4.2 / v1.4.1 升级：** Android、Windows 和 macOS 的正式发行版本可以在应用内检查并安装更新；也可从上方链接下载安装。iOS 用户使用原有签名和安装方式更新。

**从 v1.4.0 升级：** 由于旧版更新协议不同，需要先手动安装新版，不能直接通过 v1.4.0 的应用内更新流程完成升级。

### 已导入 EPUB 的新排版

本次 EPUB 解析器版本由 **33 升至 35**。此前导入的 EPUB 仍可阅读，但新增的部分图片定位、SVG 布局和样式解析改进需要重新解析原书才能生效。

Shiori 会在条件安全时尝试自动更新旧书的解析结果；你也可以在本地书籍管理中选择「重新解析」。**无需删除原书重新导入。** 阅读位置和书签会尽量保留，无法安全迁移时仍采用保守处理。
