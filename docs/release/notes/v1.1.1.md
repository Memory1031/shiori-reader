# Shiori 1.1.1

本次修复 EPUB 样式兼容问题，并接入 iOS TestFlight 发布流程。供个人与私下测试使用。

## 更新内容

- 修复 EPUB 样式表通过 CSS `@import` 引入其他样式时未完整生效的问题，改善部分书籍的首行缩进与特殊页显示。
- 样式导入保留加载顺序，处理相对路径、循环引用和媒体条件，并限制导入深度与总量。
- 新增使用开发者账号的 iOS 签名构建及 TestFlight 上传流程。

## 升级提醒

- 已导入的 EPUB 不会自动重新解析。需要应用样式修复时，请使用“更多 → 本地文件 → 书籍菜单 → 重新解析”，尽量保留阅读位置；不要通过删除再导入来更新。
- Android 继续提供签名 APK；覆盖安装需保持原签名。iOS 通过 TestFlight 分发，具体可用时间取决于上传、Apple 处理及测试分发状态；构建成功不等于已可安装。
- 本次仍不支持完整 CSS、固定版式或 DRM 解密，不包含整书在线下载或云同步。
