# Shiori 1.1.5

本次新增插图全屏预览与 EPUB 内联链接，并修复阅读器底部弹层配色与翻页时图片页闪烁。

- 阅读器中的插图可点击放大：暗色全屏视图，支持双指缩放、双击缩放 / 复位与拖动平移；说明文字不占用点击区域，关闭后保持原阅读位置。
- EPUB 正文内作者标注的链接可在章内与跨章跳转，与脚注、本章链接菜单协作；解析器保留跨段落的链接范围。
- 阅读器内打开的脚注、章节进度等底部弹层改为跟随当前纸张主题配色，不再使用应用表面色。
- 翻页时图片页不再闪烁灰底占位；导入时读取图片头部并记录固有尺寸，分页按真实尺寸预留空间，首次解码后不再触发重排。
- 解析器版本 4 → 5：已导入的旧书需在本地文件菜单中使用「重新解析」后才能应用内联链接与图片尺寸记录，无需删除后重新导入。

Android 覆盖安装需保持原签名；iOS 是否可安装以 TestFlight 处理及测试分发状态为准。
