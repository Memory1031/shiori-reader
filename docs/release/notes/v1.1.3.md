# Shiori 1.1.3

本次新增本地多文件批量导入，并修复 LightNovel 图片加载与章节末尾阅读位置两类问题。

- 本地导入支持一次多选或多文件分享：应用内确认一次后按顺序逐本导入，单个文件失败只标记该项并继续，失败与未处理项保留供重试，放弃导入不删除原文件或已入库书籍。每批最多 64 个文件、单文件 128 MiB、整批累计 512 MiB。Android 与 iOS 的分享扩展均支持。
- LightNovel 章节图片与封面允许 `lightnovel.fun` 的资源子域（如 `res.lightnovel.fun`），仍保持严格 HTTPS 校验；API 请求范围不变。无效图片改为保留占位与周围正文，不再影响章节其余内容。
- 阅读器在章节末尾遇到图片延迟加载触发重排时，保持章节末尾位置不变，不再跳回与占位同页的文本位置。

Android 覆盖安装需保持原签名；iOS 是否可安装以 TestFlight 处理及测试分发状态为准。LightNovel 子域图片在 iOS 端的运行时表现未做实机验证。
