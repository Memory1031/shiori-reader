# Shiori 1.3.0 Beta 6

这是 Shiori 1.3.0 的第六个测试构建，内部构建号为 **16**。

1.3.0 的主要目标是重新整理 Windows 桌面体验：在保留 Android / iOS 现有触摸交互的同时，将 Windows 从原先以移动端页面为基础的宽屏适配，升级为更完整的桌面阅读工作区。

本次 Beta 已基本完成 1.3.0 的 Desktop UI 与宽屏 Reader 调整，接下来将以实际使用、升级兼容和问题修复为主。

## Windows 桌面工作区

Windows 主界面现在使用统一的桌面导航与 Workspace 结构。

- 书架、搜索、本地文件、离线内容、关于与更新等一级页面统一使用桌面侧栏 / 导航栏。
- 各页面使用稳定的顶部工具栏，切换页面时标题和操作区域不再随着正文宽度左右移动。
- 不同页面根据内容类型保留各自合适的最大宽度，而不是简单把移动端页面拉伸到整个窗口。
- 窗口缩放时会在顶部导航、窄侧栏和完整侧栏之间响应式切换，同时尽量保持当前页面、滚动位置和交互状态。
- 主内容滚动区域覆盖整个 Workspace，滚动条保持在窗口内容区域最右侧，左右留白区域也可以直接使用鼠标滚轮滚动。

## 书架与搜索

桌面书架和搜索页面重新调整了信息密度与宽屏布局。

- 书架支持网格与列表两种布局，并分别保存滚动位置。
- 调整宽屏封面、列表行、继续阅读区域以及页面留白，使内容在大窗口下保持集中而不过度拉伸。
- 鼠标悬停、右键菜单以及键盘操作更加符合桌面使用方式。
- 搜索框与结果区域使用统一内容轴，宽屏下不会出现输入框与搜索结果错位。
- 修复移动端搜索页面主滚动控制器的归属问题，保持 Android / iOS 原有滚动行为。

## 本地文件

本地书库现在有独立的桌面页面。

- 可以集中查看已经导入的 TXT / EPUB。
- 保留格式筛选、导入、详情、删除与重新解析能力。
- 旧书可以直接从书籍菜单重新解析，无需删除后重新导入，并尽量保留原阅读位置。
- 桌面端支持鼠标、右键菜单以及键盘菜单操作。
- 重新解析、删除等操作继续使用原有数据与进度保护逻辑。

## 离线内容与缓存

离线内容管理也已经适配桌面 Workspace。

- 统一展示当前缓存占用情况。
- 可以展开查看各书的离线章节。
- 支持按书清理以及统一清理缓存。
- 从缓存页面进入离线 Reader，再返回时保持原页面状态与展开状态。

## 小说详情

小说详情页重新整理为适合宽屏浏览的布局。

- 封面、简介、基础信息和目录在宽屏下使用更合理的分栏。
- 目录可以独立滚动，主页面滚动与侧栏互不干扰。
- 从详情进入 Reader 后，返回时继续回到原来的 Workspace 导航栈。

## 宽屏阅读器

Reader 是 1.3.0 另一项主要调整。

- 当可用宽度足够时，正文自动进入双页模式。
- 每一栏保持独立的正文宽度与中缝，不会无限拉宽文本行。
- 键盘方向键、PageUp / PageDown、鼠标滚轮与页面点击均可用于翻页。
- 目录、阅读进度、排版设置、笔记与脚注等内容在 Windows 上使用桌面面板显示，不再完全沿用移动端底部弹层。
- Reader 仍然作为全窗口页面打开，退出后恢复之前的书架、搜索、详情或本地文件页面。

### 正文插图

本次还调整了宽屏双页中的插图分页方式。

之前较大的正文插图会独占整个双页画面，可能出现：

`文字 + 空白 → 插图 → 文字 + 文字`

现在正文章节中的整页插图仍然独占一栏，但可以与相邻页面正常组成双页，例如：

`文字 + 插图 → 文字 + 文字`

插图也可以位于左栏，两张连续插图也可以组成一组双页。

同时：

- 图片和图注按照实际单栏宽度计算尺寸。
- 图片在自己的栏内垂直居中，另一栏的正文仍从顶部开始。
- 窗口在单双页之间切换时继续按照语义阅读位置恢复。
- 图片真实尺寸延迟加载后重新分页时，也会尽量保持当前阅读位置。
- 纯图片章节仍然保持单页限宽居中。
- 特殊 EPUB 原版式 / WebView 页面不受此次规则调整影响。

## 阅读位置与翻页

1.3.0 期间也补充了多项 Reader 状态和生命周期处理。

- 调整窗口大小、切换单双页布局后按照语义位置恢复，而不是依赖像素位置。
- 改善离开 Reader、切换主题或重新布局时的阅读位置保持。
- 修正从目录跳转到前后章节时的翻页动画方向。
- 改善章节标题与正文分页边界。
- 改善图片尺寸晚到、图片重新分页以及图片资源释放时的状态保持。
- 前后翻页使用一致的分页边界，减少插图附近出现重复页或跳页的可能。

## 关于与更新

“关于与更新”页面已经加入桌面 Workspace。

保留现有：

- 当前版本与 Release 信息
- Stable / Beta 更新通道
- 自动检查更新
- 手动检查与取消
- 下载进度
- 安装状态
- GitHub 项目入口
- 开源许可
- 版本信息复制

桌面端主要调整布局与交互，没有重新设计原有更新逻辑。

## 外观与界面一致性

本轮同时整理了桌面端多个页面的基础视觉与交互。

- 统一主要页面的顶部 Chrome、间距与内容轴。
- 调整浅色 / 深色主题下的卡片与摘要区域。
- 改善强调色选择状态的显示。
- 针对中英文、较大系统文字和不同窗口宽度补充布局适配。
- README 已更新 Windows 与 Android 产品截图。

## 移动端

1.3.0 的主要改动集中在 Windows，但共享组件仍保持 Android / iOS 的移动端交互。

- 宽屏 Android / iOS 不会自动切换到 Desktop Workspace。
- 移动端继续使用 AppBar、底部弹层以及触摸优先的页面结构。
- Reader 的双页判断仍然只根据可用阅读宽度，因此足够宽的平板横屏仍可以进入双页阅读。
- 修复移动端搜索页面的主滚动区域。

## Beta 测试重点

这是测试版本，如果方便，欢迎重点观察以下场景：

- Windows 不同窗口大小下切换书架、搜索、本地文件和详情页面。
- 本地 TXT / EPUB 的导入、重新解析以及旧阅读位置恢复。
- 宽屏 Reader 的正向 / 反向翻页。
- 正文插图位于双页左栏或右栏时的显示效果。
- 带图注的插图、连续插图以及图片尺寸延迟加载后的重新分页。
- 单页 ↔ 双页窗口切换后的阅读位置。
- Reader → Detail / Shelf / Search 后返回时的页面状态。
- 深色模式、不同强调色以及高 DPI Windows 显示。
- 从旧 Beta / 正式版覆盖升级后的书架、设置与阅读进度。

如果遇到问题，反馈时请尽量附上系统版本、窗口大小、书籍格式以及复现步骤。

## 已知分发限制

- Windows 当前仍提供 **未签名的 x64 便携 ZIP**，不包含安装器或 MSIX。
- 请完整解压 ZIP 后再运行 Shiori，不要直接从压缩包内启动。
- EPUB 原版式页面依赖系统安装 **Microsoft Edge WebView2 Runtime**。
- Android / Windows 的自动更新仍建议在 Beta 阶段重点验证实际升级流程。
- Windows 10、部分高 DPI / 输入法组合以及不同 Android / iOS 设备仍需要更多实际设备反馈。
