# Shiori 1.3.0 Beta 6

这是 1.3.0 的第六个测试构建，内部构建号为 16。本版将 Windows 桌面端整理为完整的阅读工作区，并改善宽屏阅读体验。

## Windows 桌面端

- 书架、搜索、本地文件、离线内容、关于与更新以及小说详情统一使用桌面导航、稳定工具栏和适合宽屏的内容布局。
- 书架支持网格与列表展示；本地文件可查看已导入书籍并重新解析，小说详情展示简介和完整目录。
- 阅读器全窗口打开，返回后恢复原工作区；提供键盘、滚轮与右键菜单操作。

## 阅读体验

- 宽屏双页阅读支持将正文中的整页插图与相邻正文页配对；纯图片章节与原版式页面仍限宽居中。
- 目录、进度、排版、笔记和脚注等面板在桌面阅读页上方打开，减少切换时的阅读中断。
- 修复离开阅读器或调整主题后阅读位置丢失的问题，并改善章节标题与图片资源的显示和生命周期管理。
- 修复移动端搜索页面的主滚动区域。
