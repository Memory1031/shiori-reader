# Shiori 1.2.1

本次新增 Windows 桌面支持，并改进宽屏阅读、EPUB 特殊页面和书内链接定位。

- Windows 提供 x64 ZIP：完整解压后运行 `shiori.exe`，支持选择或拖入 TXT / EPUB，沿用本地书架、阅读进度、设置和缓存。
- 宽屏正文自动切换双页，增加中间留白和淡中缝；封面、整页插图与保留原版式的 EPUB 页面保持限宽居中。窗口尺寸变化后重新分页并保留阅读位置。
- 桌面支持方向键、PageUp / PageDown 和鼠标滚轮翻页，Esc 关闭弹层与图片预览。改进滚轮连续事件处理，导入弹层打开时隔离背后阅读器的键盘焦点。
- 改善书架宽屏布局、卡片悬停与选中反馈，并为 Windows 补齐启动页样式。
- EPUB 原版式页面统一使用 `flutter_inappwebview`，修复 Windows 页面显示、主题背景和退出时的原生崩溃问题。
- 图片预览增加底部留白，改善完整图片的视觉边界。
- 修复 EPUB 书内链接跳入长段落及返回时的字符位置偏移。此前导入的书籍可在「本地书籍」中重新解析，以应用新的定位信息，无需删除重导。

Windows 包未签名，原版式 EPUB 页面需要 WebView2 Runtime；完整固定版式 EPUB 仍不在支持范围内。更新时先关闭应用，再将新版完整解压到独立目录，书架与进度保留在应用数据目录。

Android 覆盖安装需保持原签名；iOS 是否可安装以 TestFlight 处理及测试分发状态为准。
