# Shiori 1.1.2

本次修复 iOS 发布构建环境，解决 1.1.1 上传 TestFlight 时因 SDK 版本过旧被拒的问题。

- iOS 构建显式使用 Xcode 26.3，并在构建前检查 iOS SDK 至少为 26。
- Android 与 iOS 均从同一发布标签构建；本次没有新增阅读功能，包含 1.1.1 的 EPUB CSS 导入链修复。
- 最低支持系统仍为 iOS 15，使用新版构建 SDK 不代表仅支持 iOS 26。

Android 覆盖安装需保持原签名；iOS 是否可安装以 TestFlight 处理及测试分发状态为准。已导入 EPUB 如需应用此前样式修复，请使用本地文件菜单中的“重新解析”，不要删除后重新导入。
