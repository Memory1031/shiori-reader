# Shiori 1.3.0 Beta 5

这是 1.3.0 的第五个测试构建，内部构建号为 15。本版重点改善本地 EPUB 的首次打开速度，并继续打磨阅读器与书架细节。

## 阅读体验

- 阅读器打开期间保持屏幕常亮，退出阅读后自动恢复系统原有行为。
- 阅读进度改为更简洁的整数百分比显示。
- 修复部分 EPUB 将章节正文拆分到多个文件时，阅读器顶部错误显示书名的问题；正文现在会继承对应的章节标题。
- 本地书没有简介时，不再显示空的「暂无简介」区域。

## 本地 EPUB 性能

- 新导入的 EPUB 会在导入阶段保存特殊页面呈现数据，之后冷启动时无需再次完整解析原始 EPUB。
- 即使一本书没有特殊页面，也会保存这一结果，避免以后重复扫描整本文件。
- SVG 特殊页面的书内跳转热点会与呈现数据一起保存，减少首次阅读时对原始 EPUB 的额外解析。
- 优化已保存呈现数据的读取流程，校验与 JSON 解析移至后台 worker，减少较大 EPUB 打开时的界面卡顿。
- 导入与「重新解析」现在共用同一套 EPUB 派生数据写入流程。

> 较早导入、且从未执行过「重新解析」的 EPUB 仍可正常阅读，但可能无法获得完整的冷启动优化。可在「本地书籍」中执行一次「全部重新解析」，使这些书使用新的存储格式。已经重新解析过的书无需为了本次更新再次处理。

## 书架与界面

- 「把喜欢的故事，留在手边」现在只在书架为空时显示，让已有内容的书架更加简洁。
- 补全并更新第三方依赖与许可证清单。

> 本版本仍为 Beta。桌面端完整 UI 重构仍在后续计划中。
