# Shiori 1.2.0

本次重点提升 EPUB 兼容性与原生阅读体验，并重新整理了本地书籍管理。

- EPUB 原生阅读新增更丰富的排版支持：保留作者设置的文字颜色、字号、粗体 / 斜体、背景色、边框与装饰框，并根据当前阅读主题调整显示效果。
- 支持 EPUB 段落与标题中的内联图片，小型图标、表情和行内插图可以随正文一起参与分页。
- 支持部分 fixed-layout / pre-paginated EPUB 页面；可还原为单张位图的页面会直接进入原生阅读流程。
- 重新设计「本地书籍」页面，增加封面、书籍数量概览、操作状态，并支持批量重新解析已导入书籍。
- 修复正向与反向翻页分页结果不一致的问题；从章节末尾返回、恢复阅读进度和章内跳转现在会回到稳定一致的页面。
- 深度跳转或恢复位置需要重新计算分页时，会保留上一页并显示加载状态，不再出现短暂空白。
- 改进 EPUB 异常样式表兼容性，并修复富文本粗斜体继承、装饰框间距和文字缩放下内联图片尺寸等问题。

EPUB 解析器已升级。此前导入的 EPUB 建议在「本地书籍」中使用「重新解析全部」，即可应用本版本新增的排版与兼容性支持，无需重新导入书籍。

Android 覆盖安装需保持原签名；iOS 是否可安装以 TestFlight 处理及测试分发状态为准。
