# Shiori 1.4.0

Shiori 1.4.0 是一次较大规模的功能与阅读体验更新。

本次更新新增了 **macOS 支持、本地全书搜索和多位置书签**，让查找内容、记录喜欢的段落，以及在不同阅读位置之间往返变得更加方便。

同时，书架新增批量管理功能，旧书的排版兼容性改进可以在安全条件下自动应用。EPUB 阅读器也进一步支持书籍内嵌字体、音频和更多原书排版样式。

## 全书搜索与书签

### 本地全书搜索

现在可以直接在阅读器中搜索整本 EPUB 或 TXT 的内容。

- 点击阅读器顶部的搜索按钮，即可查找书中的文字。
- 搜索结果展示对应的章节和前后文，方便判断是否是想找的内容。
- 选择结果后直接跳转到对应位置，并高亮匹配文字。
- 搜索过程中可以继续浏览结果，关闭搜索后也能回到原来的阅读位置。
- Windows 支持 `Ctrl+F`，macOS 支持 `⌘F`。

全书搜索目前适用于**本地导入的 EPUB 和 TXT**，暂不支持在线书籍的全书搜索。

### 多位置书签

新增用户书签功能，可以为同一本书保存多个阅读位置。

- 通过阅读器更多菜单添加或取消书签。
- 在「我的书签」中集中查看、跳转或删除。
- 本地书籍与在线书籍均支持书签。
- 修改字号、纸张设置或窗口大小后，书签会尽量保持准确定位。
- 清理缓存或阅读历史不会删除已保存的书签。

书签会随着对应书籍的删除而移除。部分特殊版式页面暂不支持添加书签。

### 阅读位置回跳

查看书签、搜索结果或 EPUB 书内链接后，现在可以方便地返回跳转前的位置。

- 跳转后会短暂显示快捷返回按钮。
- 按钮隐藏后，仍然可以通过阅读器更多菜单返回。
- 支持连续查找，以及书签、搜索和书内链接之间的多次跳转。
- 跨章节查看内容后，也可以逐步回到之前的阅读位置。

阅读时不必再担心查找某段内容后找不到原来的位置。

## 全新 macOS 版本

**Shiori 正式增加 macOS 支持。**

macOS 版本延续现有的桌面阅读体验，支持：

- 本地 EPUB/TXT 导入与阅读。
- 拖入文件或通过 Finder 打开书籍。
- 键盘快捷键、鼠标和滚轮翻页。
- 宽屏双页阅读、书架管理、全文搜索和书签。
- 在线阅读、离线缓存及应用内更新。

GitHub Releases 提供同时适用于 **Apple Silicon 和 Intel Mac** 的通用 DMG，系统要求为 macOS 12.0 或更新版本。

**安装提醒：** macOS 版本未经过 Apple 开发者身份签名及公证，首次打开时可能受到系统安全机制限制。请将应用复制到「应用程序」文件夹或其他可写位置后运行，不要直接在 DMG 中使用应用内更新。

## 书架与本地书籍管理

### 批量管理

书架和本地文件管理现在支持多选操作。

- 一次选择多本书籍进行移除。
- 批量重新解析本地 EPUB/TXT。
- 查看每本书的处理结果。
- 处理过程中可以停止，已经完成的操作不会被撤销。

批量操作会在执行前提示确认，减少逐本处理的重复操作。

### 旧书自动更新解析

此前导入的 EPUB/TXT，现在可以在适当条件下自动应用新版解析器的兼容性改进。

- 不需要为了获得新的排版支持而删除原书、重新导入。
- 自动更新会尽量保留已有阅读位置和书签。
- 如果无法可靠恢复位置、文字编码存在歧义或遇到其他问题，会保留原来的书籍数据。
- 仍然可以从本地文件管理中手动选择「重新解析」。

旧书在后台分批处理，符合条件的书籍会陆续应用新版解析结果。

### 其他书架改进

- 「继续阅读」优先展示尚未读完的书籍。
- 书架的网格或列表布局选择现在会被记住。
- 优化导入结果提示，更清楚地区分新增书籍、已有书籍和导入失败。
- 改善批量导入的取消、重试与待处理文件保留。
- 优化书架滚动区域和部分管理操作的交互。

## EPUB 阅读兼容性增强

1.4.0 继续扩展 Shiori 对轻小说 EPUB 的原生分页支持。

### 更多原书排版样式

- 支持部分 EPUB 内嵌的 TTF/OTF 字体，尽量保留作者指定的文字样式。
- 改善带有背景图片、边框、圆角及装饰元素的页面显示。
- 支持更多简单表格和装饰性标题结构。
- 改善封面、扉页、插图和书中目录的布局。
- 为部分原书缺少目录入口的封面、彩插和前置页面补充导航位置。
- 改善书内链接及特殊版式页面的定位、显示和返回行为。

对于无法完整还原的复杂样式，阅读器仍然优先保证文字可读，而不是强行显示可能错乱的排版。

### EPUB 内嵌音频

部分 EPUB 包含作者提供的音频内容，现在可以在阅读器中使用相应的播放与暂停控件。

目前支持符合条件的包内 MP3 和 WAV 文件。音频不会自动播放，也不支持后台播放或与正文同步朗读。

### 阅读器细节

- 翻页时的章节进度显示更加及时。
- 从搜索结果、书签或书内链接跳转时，增加更自然的位置切换效果。
- 打开目录后，可以更方便地找到当前阅读的小节。
- 关闭并重新打开目录时，在适当条件下保留之前浏览的位置和展开状态。
- 阅读设置与弹出菜单的颜色更加统一，暖纸和夜间主题下的显示效果进一步改善。
- 优化部分阅读加载、翻页和位置恢复场景，减少不必要的画面变化。

## 在线阅读与离线体验

- 优化在线书籍的目录加载与刷新，缺少目录数据时可按需获取。
- 阅读器目录可以标记当前正文小节。
- 在线书籍的已缓存内容现在可以直接从缓存管理页面打开阅读。
- 改善章节预取、离线内容切换和取消操作的稳定性。
- 优化网络异常、阅读进度保存失败等情况的提示与重试。

在线阅读仍依赖第三方书源，已缓存内容的离线可用性取决于实际保存的章节和资源。

## 界面与稳定性改进

- 调整 Android、iOS 和 Windows 的原生启动画面，使其与 Shiori 的整体视觉更加一致。
- 统一部分操作成功、失败和重试提示的显示方式。
- 改善正常退出应用时的阅读进度保存。
- 提高导入、删除、重新解析以及缓存管理过程中的数据处理可靠性。
- 修复多项涉及阅读位置、章节切换、异步加载和取消操作的问题。

## 下载与安装

1.4.0 通过 GitHub Releases 提供以下安装文件：

| 平台                 | 分发方式                         |
| ------------------ | ---------------------------- |
| Android 7.0+       | 已签名 APK                      |
| Windows x64        | 便携 ZIP                       |
| macOS 12.0+        | Apple Silicon / Intel 通用 DMG |
| iOS / iPadOS 15.0+ | 未签名 IPA，供用户自行签名安装            |

**iOS 安装与更新：** GitHub IPA 需先通过自选工具签名，再安装到设备，后续通过原签名方式更新。应用内导入可在缺少 App Group 授权时使用；系统分享扩展还需正确的签名和 App Group 配置。

Android、Windows 和 macOS 的正式发布版本支持通过应用内检查更新。iOS 的安装与更新仍由用户采用的签名或分发渠道管理。

## 升级前请注意

**在线书籍移除行为有所变化。**

从 1.4.0 开始，确认将在线书籍从书架或详情页移除时，会同时清除该书的阅读进度、用户书签和相关缓存。这与 1.3.1 中移除在线书籍后保留阅读历史的行为不同。

如果只是想释放存储空间，请使用**清理缓存**，不要移除书籍。单独清理缓存不会删除阅读进度和书签。

本地书籍的移除仍会删除 Shiori 保存的导入副本、解析内容、阅读进度与书签，但不会影响设备上的外部原文件。

已有本地书籍升级后可以继续阅读。新的 EPUB 排版支持会在安全条件下逐步应用；如遇到排版问题，可以尝试通过「重新解析」更新书籍内容。

Shiori 仍以本地 EPUB/TXT 阅读为核心，不支持 DRM 保护书籍、PDF、完整固定版式 EPUB 或云同步。
