# Shiori 1.4.1

Shiori 1.4.1 重点改善了 **EPUB 图片排版与阅读主题适配**，并重新设计了跨平台应用更新机制。

本次更新还为 Windows 增加了正式安装版 EXE，推出中英文官方网站，改进了封面、插图、书签及部分特殊 EPUB 内容的显示体验。

## EPUB 图片与排版改进

### 更准确的图片尺寸

修复部分 EPUB 中小型装饰图片被异常放大、占满阅读区域的问题。

- 普通图片优先按照原始尺寸显示，超出页面可用空间时再等比缩小。
- 正确处理 EPUB 中通过 CSS 或 HTML 属性声明的图片宽度、高度及最大尺寸。
- 改善封面、彩插和独立图片页的居中及缩放行为。
- 修复双页阅读下部分独立图片被错误分栏的问题。
- 保留正文图片与文字之间的间距及作者指定的布局。
- 优化图片较多章节的布局处理。

较小的章节分隔符、装饰图案现在不会仅因为独占一个内容块就被当成整页插图。

### 图片背景适配阅读主题

改善白色背景的文字图、线稿和小型黑白装饰图片在不同阅读主题下的显示效果。

符合条件的图片可以自动融入当前纸色，在白纸、暖纸和夜间主题下保持协调。

彩色插画、照片、透明图片及无法可靠识别的图片仍保留原始显示效果。查看原图或导出图片时，也不会修改原始内容。

### 阅读位置与书签

- 改善封面和独立图片页的阅读位置恢复。
- 修复部分图片页前后存在空白内容时的分页问题。
- 优化图片页的书签定位和重新解析后的位置迁移。
- 调整桌面端书签界面的布局与显示细节。

## 全新的 Windows 安装版

Windows 现在提供两种发行方式。

**安装版 EXE（推荐）**

- 提供标准安装向导、开始菜单快捷方式和卸载功能。
- 默认安装到当前用户目录，无需管理员权限。
- 支持应用内自动下载和安装后续更新。
- 更新或卸载时保留独立存储的书库、阅读进度和用户设置。

**便携版 ZIP**

- 完整解压后即可运行，无需安装。
- 不创建系统安装记录。
- 继续支持应用内自动更新。

两种版本共用阅读功能，但各自采用适合其安装方式的更新流程。

## 跨平台自动更新改进

重新设计 Android、Windows 和 macOS 的应用内更新机制。

- 使用统一的签名更新清单，减少重复的发布文件。
- 保留签名清单验证与更新包的 SHA-256 完整性验证。
- Windows 安装版使用新版安装器升级，便携版继续使用 ZIP 更新。
- macOS 直接使用 DMG 完成安装和自动更新，不再额外提供更新 ZIP。
- 改善升级失败后的状态恢复及用户文件保护。
- 清理可安全识别的旧版更新缓存和临时工作目录。

GitHub Release 附件也由原先的大量安装包、校验文件和平台元数据，精简为 **5 个安装包和 1 个签名更新清单**。

### 安装注意事项

**Windows：** 推荐使用 EXE 安装版。便携版需要先完整解压 ZIP，再运行 `shiori.exe`，不要只提取单个可执行文件。

**macOS：** 打开 DMG 后，将 Shiori 拖入「应用程序」文件夹。当前版本未经过 Apple Developer ID 签名和公证，首次启动时可能需要在系统「隐私与安全性」中确认。请勿直接在 DMG 内运行应用进行更新。

**iOS：** IPA 未签名，不能直接安装到 iPhone 或 iPad。用户需要自行完成签名和后续版本更新，部分功能可能依赖正确的 App Group 授权。

### 从 v1.4.0 升级

**重要：v1.4.1 使用新的自动更新协议，v1.4.0 无法通过旧版应用内更新机制直接升级到此版本。**

请从上方链接手动下载并安装 v1.4.1。

已有书库、阅读进度、书签和偏好设置独立保存在用户数据目录中，正常升级时会予以保留。

安装 v1.4.1 后，Android、Windows 和 macOS 的正式发行版本将继续支持后续版本的应用内自动更新。

如果已有本地 EPUB 的排版尚未更新，可以等待应用在安全条件下重新解析，或通过本地文件管理中的「重新解析」手动更新。
