# Shiori 0.1.0+1 私下测试说明

当前版本用于个人 / 私下测试，GitHub 仓库为 private，tag 产物通过私有仓库 Release 提供给具备相应访问权限的人；尚未完成正式发布验收。

- 支持在线搜索、书架、继续阅读、图文阅读与已缓存内容离线阅读。
- 支持系统文件选择 / 分享导入 TXT 和无 DRM EPUB；不附带小说内容。
- 在线功能依赖第三方内容及媒体服务，查询与请求会发送给相应服务；可用性可能变化，不代表与内容服务有官方合作关系。
- 书架、阅读进度、偏好与导入文件存储在应用本地。Android 系统备份 / 换机迁移可能包含这些用户数据；缓存和导入暂存按配置排除。
- 本轮核对的包为 Release 编译、Debug 签名；不是正式签名候选。更换签名可能无法直接覆盖安装，卸载会删除应用数据，不应为安装新包直接卸载现有版本。
- 角色品牌素材来源为《更衣人偶坠入爱河》的乾纱寿叶，当前没有授权证明；书源接入及内容许可也仍未确认。本说明不授予小说或素材再分发权。
- Android 已有前序真机验证；iOS 完整运行与发布验收未完成。

具体构建哈希、检查范围和未决项见 [Android 审计](android-audit.md)。本说明不表示已执行新一轮真机安装或签名发布。
