## 保留的边界

- 旧书不会自动重解析；特殊页版本不匹配可能退回普通文字，手动重新解析可恢复。尚无自动提示。近似位置迁移会提示，不保证原行。
- 本地 EPUB 尊重可识别的原始缩进，没有指定时不自动补两字；完整 CSS、固定版式、DRM、内联脚注点击不在本轮范围。
- Android 12 真机主要流程通过；iOS 用户确认特殊页重解析恢复并同意整体验收，未逐项提供证据。取消操作、动画性能及完整系统生命周期矩阵未实测。
- ANDROID-002 的磁盘写满和系统备份恢复此前由用户明确跳过，不重新作为阻塞项。
- 分发仍为个人 / 私下测试；代码许可证、角色素材和书源内容许可边界见[发布说明](release/README.md)。

## 开发约定

从 develop 继续开发，保留用户工作树。自动测试默认离线；真实书源请求需显式授权。验收文件由用户自行维护，专用生成样本和截图已删除，通用回归保留。历史任务设计与执行过程查 Git，当前行为以主题文档为准。
