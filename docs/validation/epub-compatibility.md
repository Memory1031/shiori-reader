# EPUB 集中兼容性核查

## 扩展扫描与修复（2026-09-08，当前结果）

Windows 上只读扫描用户明确提供的 **35 个文件（34 个不同 SHA-256）**。修复前 **23 / 35 可解析、12 / 35 失败**；修复后 **34 / 35 可解析**。`1.epub` 与 `玩乐关系1(1).epub` 字节相同，因此不是 35 本独立内容。

可解析文件合计 **1,068 个章节、763 次图片引用、535 个目录条目**；输出的目录章节 / blockKey 全部有效。按明确的隐藏内容 / ruby 括注策略核对，文字顺序和图片哈希顺序差异均为 0，普通图片引用无残留缺图。跨文件去重的 **508 张图片**全部通过宿主 Flutter 32px 宽首帧解码。统计按文件累计，包含重复文件；解码不代表手机上完整尺寸、动画所有帧、分页 / 裁剪已经验收。

保留 8 个特殊 HTML 页；内嵌图片顺序另做核对，详见结构化结果。两个无可读内容的 spine 项被跳过（义妹生活 10 的 pre.xhtml、玩乐关系 2 的 nav.xhtml），nav / NCX 仍独立读取。没有修改原件、导入 / 删除用户书库、联网访问书源、启动模拟器、打包或安装应用。

唯一仍拒绝的文件是 **`[三河ごーすと].义妹生活.11.[日翻].epub`**：encryption.xml 含 RSA / AES 声明，CipherReference 指向 dkagent.css，不属于已支持的字体混淆。本轮仅识别声明，没有解密，也不推断整本正文均已加密；沿用现有 DRM 不支持边界。

### 方法、复现与边界

完整逐文件 SHA-256、修复前失败类型、修复后结构与图片解码结果见 [JSON](epub-compatibility.json) 的 `expandedAudit`。旧两本核查仍保留在原字段。原件、正文、图片及机器绝对路径不提交仓库。

运行 `dart run tool/epub_compatibility_audit.dart paths.json report.json`，paths.json 是调用者明确提供的文件路径数组。普通 CI 不扫描 Downloads。文本基准先用 XML 去掉 script 并处理 HTML 命名实体，不合法 XML 回退 HTML；按 spine 比较并去空白，再应用明确的隐藏 / ruby / 缺图占位规则。CSS 映射复用生产有限子集，因此这不是独立 CSS 正确性证明；优先级 / 条件规则另由自制测试验证。图片比较 ZIP 字节 SHA-256 与顺序，而不只计数。

设置 `EPUB_AUDIT_INPUT` / `EPUB_AUDIT_OUTPUT` 后运行 `flutter test --no-pub tool/epub_image_audit_test.dart` 可显式复验宿主解码。不同 shell 自行设置环境变量，机器路径不进入跟踪配置。

新增 **13 项自制兼容回归**；与原有 parser / presentation 联合 48 项通过；完整 **426 项离线测试通过、analyze 无问题**，真实图片解码另 1 项通过。没有新增依赖或修改模型 codec。iOS / Android 设备排版、字体、裁剪和阅读连续性未由本轮验证。

本轮属于导入时解析变更，可能改变 blockKey / revision；旧 manifest 不会自动重解析，重复导入仍去重。当前删除重导会清进度，本轮没有自动执行这些操作；保留位置的重解析入口不在本轮范围。仍不支持完整 CSS、任意 SVG 绘图、全部条件媒体查询、DRM / 固定版式；未知条件保守降级可能影响装饰或屏幕特定内容。旧 ZIP 安全回归保留，但本轮不是完整安全审计。

## 已修复：首行缩进被源码空格抵消

第一本声明 `p { text-indent: 2em; }`，4018 个 p 中有 4017 个带源码换行 / 缩进。解析器把源码空白压成段首普通空格，渲染器发现前导空格便不再添加 CSS 缩进。在需要缩进且左对齐的 4015 个解析段落中，4014 个因此被跳过。

修复将 HTML 可折叠空白限定为 ASCII 空格、TAB、CR、LF、FF，并清理普通块的边缘可折叠空白。保留 `pre`、NBSP、全角空格、段内英文空格；跨页续段不重复首行缩进。修复后第一本误跳过数为 0；第二本仍有一段因原文显式前导空白而不补缩进，属于避免双重缩进的规则。

回归位置：`test/data/local/parsers_test.dart` 的 `HTML source whitespace does not suppress CSS first-line indentation`。注意这是导入解析变更，可能改变块摘要；旧 manifest 不会自动重解析，重复导入仍会去重，不能承诺只更新应用就改变已导入书的排版。当前删除重导会清进度；未来应提供保留位置的重新解析入口。
