## 已修复：首行缩进被源码空格抵消

第一本声明 `p { text-indent: 2em; }`，4018 个 p 中有 4017 个带源码换行 / 缩进。解析器把源码空白压成段首普通空格，渲染器发现前导空格便不再添加 CSS 缩进。在需要缩进且左对齐的 4015 个解析段落中，4014 个因此被跳过。

修复将 HTML 可折叠空白限定为 ASCII 空格、TAB、CR、LF、FF，并清理普通块的边缘可折叠空白。保留 `pre`、NBSP、全角空格、段内英文空格；跨页续段不重复首行缩进。修复后第一本误跳过数为 0；第二本仍有一段因原文显式前导空白而不补缩进，属于避免双重缩进的规则。

回归位置：`test/data/local/parsers_test.dart` 的 `HTML source whitespace does not suppress CSS first-line indentation`。注意这是导入解析变更，可能改变块摘要；旧 manifest 不会自动重解析，重复导入仍会去重，不能承诺只更新应用就改变已导入书的排版。当前删除重导会清进度；未来应提供保留位置的重新解析入口。

## 已复现但未修改的兼容缺口

以下来自合成样本，不表示两本实际文件都触发。优先级以内容丢失 / 导入失败优先，其次文字和样式准确性。

| ID | 优先级 | 最小触发条件 | 当前结果 / 建议 |
| --- | --- | --- | --- |
| EPUB-A01 | 高 | spine 中一个 XHTML body 仅有空白 | ChapterContent 抛 ArgumentError，整本解析中断。应允许空页面或明确跳过并维护目录目标，不能因装饰空页拒绝全书 |
| EPUB-A02 | 高 | `position:absolute` 容器内含 SVG `<image>` | 原生解析有 ImageBlock，但特殊 HTML 白名单删除 svg，生成页面没有内嵌图片。应保留安全位图或回退原生，避免选择特殊页后丢图 |
| EPUB-A03 | 中 | `.hide {display:none}` 对应普通段落 | 隐藏文字作为正文出现。需处理明确隐藏内容与目录锚点关系，避免无条件删除可能供注释使用的内容 |
| EPUB-A04 | 中 | `text-indent:2em !important; text-align:center !important` | 缩进变成 0、对齐变 start。需解析 important 与优先级，不只把声明尾缀作为值 |
| EPUB-A05 | 中 | `<ruby>漢<rt>かん</rt></ruby>字` 无 rp | 原生输出 `漢かん字`，读音与正文连在一起。应保留注音结构或明确括注降级；现状没有统一降级 |
| EPUB-A06 | 中 | 竖排样式直接设在 body | 特殊页检测仅查询 body 后代，漏掉 body 自身，未启用特殊排版 |
| EPUB-A07 | 低 | 本地图片引用带 `?v=1` 查询部分 | epubReference 拒绝查询，输出占位。可讨论仅对包内引用安全忽略查询，继续禁止外部资源 |

复现方式：复用 `test/data/local/support/epub_fixtures.dart`，只替换 `OPS/text/a.xhtml`，使用 EpubParser 的 `includePresentations: true`；观察 blocks、leadingIndent、alignment 和 presentations 是否包含 `data:image/`。上述样本没有网络或真实版权内容。核查用临时脚本不作为“正确行为”断言提交，避免将缺陷锁成预期。
