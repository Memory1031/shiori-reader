## 已执行记录

本次用户确认 Mac 环境可用并授权模拟器启动检查；开发文档中的 Windows / `DEFERRED_NO_MAC` 记录保留为历史证据，不代表本机现状。验证范围为正式入口的模拟器构建与启动，不自动完成 IOS-001 全部验收，也不代表 iPhone / 签名 / 发布通过。

- 环境：macOS 26.3.1 (a) / build `25D771280a`；Xcode 26.5 / build `17F42`；Flutter 3.38.4 / Dart 3.10.3；CocoaPods 1.16.2。
- 现有 iPhone 17 Pro / iOS 26.2 模拟器已通过 `simctl bootstatus -b` 启动。初次检查时 Xcode 提供 iOS / iOS Simulator 26.5 SDK，但缺少对应 26.5 runtime，`xcodebuild -showdestinations` 未列出合格 iOS 目标；后续已补齐 iOS 26.5 (23F73) ARM64 runtime。
- 首次 `fvm flutter build ios --simulator --debug --target lib/main.dart`：**FAIL（环境）**，CocoaPods 安装通过，Xcode 在目标选择阶段报 `iOS 26.5 is not installed`，未进入应用源码编译。随后使用 `xcodebuild -downloadPlatform iOS -buildVersion 26.5 -architectureVariant arm64` 补齐运行时，8.52 GB 下载与安装均通过。用户将 Apple CDN 改为直连后，实测约 14 秒从 1.43 GB 增长到 1.84 GB（约 29 MB/s），随后完成下载。
- 按用户建议显式执行 `fvm flutter run --debug --no-pub --target lib/main.dart -d F2CDF780-3E4E-4972-A579-E5B1DC094802`，指定已启动的 iPhone 17 Pro / iOS 26.2：**FAIL（同一环境阻塞）**，Xcode 仍仅列出 `iOS 26.5 is not installed` 的不合格目标。说明缺少匹配 runtime 时不能仅通过指定设备 ID 绕过；这不表示应用最低版本要求 iOS 26.5。补齐 26.5 runtime 后，**同一命令在原 iOS 26.2 模拟器上构建、安装与启动 PASS**，Xcode 编译用时 70.5 秒。
- 保留 CocoaPods 生成的工程 / workspace 集成、Debug / Release xcconfig 包含项及 `Podfile.lock`；Podfile 显式固定 `platform :ios, '15.0'`，与工程最低版本一致。未变更 Dart 依赖或应用业务逻辑。CocoaPods 仍提示 Profile 基础配置使用自定义 xcconfig；当前 Profile 复用 Release xcconfig，Profile 构建未验证。
- 正式入口运行证据：观察到启动页与随后可交互的中文搜索页，Dart VM Service 正常连接；模拟器应用容器已生成生产 `users.sqlite` 与 `cache.sqlite`。本次未主动执行真实 Source 请求；后续用户自行操作不计入自动化验证。截图保存在 Git 忽略的 `.tooling/evidence/ios-smoke/`。为避免打断用户操作，未替换当前应用运行数据库探针，完整 CRUD / 重开、冷启动及 Reader 验收仍待补齐。
