# UX-001 交互核查

日期：2026-09-08。范围：保留当前 UI，检查 Android 交互及 iOS Level A 兼容性，不重做页面设计。

## 检查与修复

发现并修复应用外观面板的明暗 ChoiceChip 勾选标记与 avatar 图标叠加：明暗选项保留原图标、选中底色和 selected 语义，不再绘制重复勾选。主题色选项继续保留勾选，颜色不是唯一状态提示。

正式首页已经移除发现 / 底部标签；搜索、导入、更多菜单继续可用，搜索来源采用中性标签。无新增平台 API、依赖或用户数据迁移。

## 证据边界

- 可访问性结果为代码、语义和点击目标自动化核查。手机未启用 TalkBack；真实朗读顺序、语音效果及 TalkBack 手势操作没有实测，不能据此宣称完整无障碍认证。
- Android 设备交互使用 ADB 触控 / 滑动 / 系统返回注入；不代证每种厂商边缘返回手势实现。
- iOS 真实 swipe-back、SafeArea 和 VoiceOver 留 IOS-003 / IOS-004，本轮没有 iOS runtime 测试。
- 真机当前仅有图片缓存，没有可直接进入的缓存正文；阅读手势使用此前构建的独立 Profile 本地样例。此样例不包含本轮外观图标修复，后者由 widget 矩阵和新的正式 Release 验证。
- 没有清应用数据或修改生产书库。临时字体 / 旋转设置已恢复为 font_scale=1.0、accelerometer_rotation=1、user_rotation=0。

本机 `.tooling/evidence/ux001-*` 保存 widget / matrix / analyze / build 日志、设备设置记录、横屏及键盘截图；这些设备证据不纳入 Git。首次新增矩阵的失败包含测试 SemanticsHandle 清理时机及滚动后裁剪边界测量问题，修正测试资源清理和逐项测量后 4 组通过，不记为应用运行故障。

真机隔离样例补验：滚动后中心点击出现操作栏，打开 Reading settings，切换 Paged，系统返回关闭面板，左右滑动后正文从约 43% 前进至 49%；读取到的新页语义节点确认换页。`reader-after.png` 截于分页动画过程中，不用于判断静态排版。最后恢复安装包含图标修复的正式 Release 包并启动成功。
