## 双端运行探针

入口 `integration_test/local_parsers_smoke.dart` 在独立的 `local003004-probe/run-*` 开发目录中运行，不读取或清空正式用户书架。只使用自建文字 / EPUB / 图片，不访问真实 Source 或网络资源；成功后关闭库并删除本次探针目录。

每端依次执行：

1. UTF-8 BOM / UTF-16 BOM / GB18030（含 GBK 和四字节 emoji）实际解码与提交。
2. 自建 EPUB 2 NCX、EPUB 3 nav 的正文 / 图片 / 嵌套锚点提交。
3. 关闭和重开数据库及 LocalBookStore，比较正文 revision。
4. 从正式托管媒体接口读取 PNG，交给 Flutter 原生图片 codec，检查宽度。
5. 检查同章不同片段锚点、重复导入不再调用解析器。

Android 最终标记：`LOCAL003004_PARSERS_REOPEN_DEDUP_IMAGE_PASS 3331ms`；iOS 屏幕最终标记：`LOCAL003004_PARSERS_REOPEN_DEDUP_IMAGE_PASS 1367ms`。这是微型 fixture 的探针耗时，不是大书性能或 release benchmark。iOS 的 `simctl --console` 重定向存在缓冲，运行判定另用实际 Simulator 截图确认，未把“控制台没有异常”当作通过。

本轮没有改动原生接收实现，因此没有重复整个 LOCAL-002 原生分享 / 选择器自动化矩阵。探针直接验证这两项任务新增的 Dart 解析、托管存储和平台图片解码；不能据此宣称已完成系统选文件后的书架阅读闭环。

## 失败与修正

- 初版探针泛型空安全类型标注导致编译失败，已修正；不是 SDK 下载问题。
- 初次 Android 探针漏建测试目录，报 PathNotFoundException；补上独立父目录创建。
- 第二次 Android 探针在图片解码处失败：测试 PNG 的 IDAT CRC / zlib 校验无效。换成自建有效的 1×1 RGBA PNG，并新增真实 Flutter codec 回归测试；生产解析 / 入库无需为此修改。
- 首轮 ZIP 负例的构造器自动改写反斜杠、以及损坏位置未命中真实 payload，使测试未真正产生预期坏包；已改为直接修改原始 ZIP header / CRC 后复验。另将压缩比夹具调整到确实超过约定阈值。
- 补充发现并修正：编码歧义不能只比较 600 字预览，必须比较完整解码结果；取消后不再创建新的编码提示；IMG / HR 自身锚点在前面仍有行内缓冲时要先 flush 再记录块位置。

## 复现

使用项目固定 Flutter 3.38.4 / Dart 3.10.3。依赖已经缓存时不需要 NDK / Flutter 下载：

```sh
PUB_HOSTED_URL=https://pub.flutter-io.cn fvm flutter analyze --no-pub
PUB_HOSTED_URL=https://pub.flutter-io.cn fvm flutter test --no-pub --reporter expanded
```

Android 探针构建使用 [开发环境](../development.md) 的 JDK 17 与现有 NDK 28.2：

```sh
JAVA_HOME="$PWD/.tooling/jdk17/Contents/Home" \
GRADLE_OPTS="-Dorg.gradle.java.home=$PWD/.tooling/jdk17/Contents/Home" \
FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn \
PUB_HOSTED_URL=https://pub.flutter-io.cn \
fvm flutter build apk --debug --target-platform android-arm64 \
  --target integration_test/local_parsers_smoke.dart --no-pub
```

安装到专用 emulator 并启动后，读取该应用 PID 的 Flutter 日志，查找 PASS。不得自动选用连接的用户真机。iOS 使用：

```sh
PUB_HOSTED_URL=https://pub.flutter-io.cn fvm flutter build ios --simulator --debug \
  --target integration_test/local_parsers_smoke.dart --no-pub
```

用 simctl 安装到测试模拟器、启动后检查日志或屏幕 PASS。复现结束重新以 `lib/main.dart` 构建并安装正式应用。
