# PARSE-008：包内辅助链接与连续阅读

2026-09-09。先更新 Domain/Reader 合同，再实现解析、存储与交互。本轮不引入浏览器导航、远程读取或新的依赖。

## 用户行为

阅读菜单的“本章链接”列出当前章节的正文链接。点击有效目标进入临时阅读页，“返回原位置”关闭该页，底层 Reader 保持挂载，因此保留当前页面、排版状态和 occurrence。临时页没有 LibraryRepository，不覆盖主书的阅读历史；最多嵌套 8 层。

本轮入口为章节链接列表，**没有实现正文文字内联点击或 WebView 链接点击**。不改变原文或把链接标记塞入段落；源文字仍正常显示。锚点定位到所属语义块起点，不承诺块内精确字符位置。

`linear=no` 仍保留在目录，可明确选读；上一章/下一章只选择主阅读顺序中的章。非 spine 辅助文档不混入主目录，若目录已有指向该文档的有效条目，选择后也进入临时页。全书没有 linear 条目时不提供连续跳章，不自行把辅助章升级为主章。

## 数据与路径

- LocalBookContent 新增 auxiliaryChapters、links、可空 readingOrder；LocalContentLink 是独立不可变侧表，包含来源章/块、短标签、目标章/块或不可用原因。
- 同文档 fragment 在重复 spine 中指向当前 occurrence；跨文档目标采用资源首次出现。返回由路由栈保留源 occurrence，不依赖文档内回链来猜测。
- 非 spine 目标只解析 manifest 声明的包内 XHTML/HTML；允许链式辅助链接和循环，但已尝试路径不重复解析。上限 64 个辅助文档、10000 条链接（含 occurrence 展开），沿用 XML/ZIP/资源/manifest 总预算。
- 远程/带 scheme 的链接、越界路径、未知格式、缺文档、缺锚点都不可用；没有原始 URL/路径传到 UI。缺锚点不会偷偷跳章首。hidden/display:none 内容不被当作可见锚点揭示；这类脚注仍属于已知限制。
- HTML 特殊页仍使用原有惰性、安全呈现策略，链接通过菜单侧表打开，未放开 WebView 导航或脚本。

## 存储与旧书

manifest v1 增加可选字段，读取时校验所有来源/目标属于同书、块存在、辅助章无重复、主顺序只引用 spine 章节；辅助图片也校验托管资源。字段缺失时辅助文档/链接为空，主顺序回退旧目录。普通读取不隐式升级。

新导入即生效；旧书需要显式重新解析才能得到新链接与 linear 元数据。重解析沿用 PARSE-005 的事务发布、位置迁移和维护失效机制；本地 parserVersion 更新为 3，数据库 schema 仍为 v4。辅助链接不参与正文 blockKey/contentRevision，因此增加交互元数据本身不改变正文身份。

## 验证范围

合成 EPUB 覆盖同章 fragment、重复 occurrence、跨章/非 spine 脚注、回链循环、linear=no、缺资源/锚点、隐藏锚点、远程/越界拒绝、文档数量限额及侧表不改变正文身份。存储测试覆盖导入、重启读取辅助正文、旧字段缺失及显式重解析升级。

widget 测试覆盖中英文菜单、脚注查看后返回同一个 Reader State、阅读历史保持、临时页不写进度、非线性章跳过、不可用链接不换页及嵌套层级限制。未运行真实书源、设备/模拟器或官方 EPUB 测试套件；不宣称所有 EPUB 脚注形式均受支持。

最终验证：完整 `flutter test --reporter expanded` 556 项通过；`flutter analyze` 无问题。未执行平台构建或运行。
