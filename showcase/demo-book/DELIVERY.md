# 原创展示小说交付报告

《蓝色借书卡的最后一栏》已完成中文正文与完整英文翻译，英文书名为 *The Last Line on the Blue Library Card*。封面按要求使用日文竖排标题「青い貸出カードの最後の空欄」，两个正文语种共用同一封面设计，不添加语种标签。

## 内容与图片

| 项目 | 实际交付 |
| --- | --- |
| 中文正文 | 七章，15,237 个汉字；计入标点与其他字符、不计空白为 17,836 字符 |
| 英文正文 | 七章，9,602 词，为完整故事翻译 |
| 正文段落 | 中文 505 段、英文 515 段，不计章名与制作说明 |
| 插画 | 一张封面、三张剧情彩插，均保留 1024 × 1536 无字 PNG 原图 |
| EPUB | 两个可重排 EPUB 3，各包含七章目录、四张图片及一处正文书内链接 |

故事发生在日本濑户内海沿岸的架空汐见町。女主七濑澪为17岁高二女生，身高约150厘米、黑色长直发、夏季水手服；藤原律是同龄男生。故事围绕旧书店搬迁与一张借书卡展开，七章完成线索揭示、人物冲突和后续选择。人物关系、1998年旧卡与2026年夏天的时间线、线索解释已保留在 `story/continuity.json`。

封面与彩插均由 ImageGen 制作，以女主为主要视觉主体。后三张参考封面人物，分别用于第一章递卡、第四章雨窗改稿与第七章新店签名；封面随后调整为女主靠左、日文标题靠右的构图。标题另用 Mochiy Pop One 排字，保留原字体与 SIL OFL 1.1，不将字体嵌入 EPUB。

两个最终 EPUB 均通过 **EPUBCheck 5.4.0**：各为零致命问题、零错误、零警告、零提示。独立校验同时检查 ZIP、XML、OPF、spine、七章目录、全部资源与片段引用、图片解码、替代文本、每一段源正文和校验摘要，确认没有缺章、重复长段、外部资源、脚本或嵌入字体。固定工具与字体渲染库下重复构建，所有分发文件字节一致。

Shiori 源码组件验收已通过中英文两个实际文件的检查：真实导入与存储重新打开、书架封面解码、七章与四张图片、普通翻页、桌面双页、章节目录跳转、全书搜索真实命中与跨章跳转、两个位置书签及书签返回、搜索跳转后位置回跳、正文插画实际字节解码与渲染。两项组件用例均通过，Dart 静态分析无问题。

这些检查使用与 v1.4.0 标签一致的未修改生产代码，在 Linux 的真实 Flutter 引擎与 Windows UI 分支中执行，配合真实托管文件、SQLite 和搜索 isolate；没有使用发布版 Windows 安装包，也没有把布局探针当作图片解码。少量正文诊断渲染另存于忽略目录，没有加入产品截图。
